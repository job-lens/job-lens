# 融职境 · JobLens Android 0.1.0

真正的原生 Android 客户端，Kotlin + Jetpack Compose，无 WebView。连接固定 HTTPS 服务 `https://j.qunxue.xyz/api/v1`，不包含生产账号、演示账号或假业务数据。

## 来源与设计

- Web/API 基线：`job-lens/job-lens`，main `790e886`（2026-10-04 审阅）。未改动或部署后端。
- `contracts/openapi.yaml` 为该版本的产品契约快照。
- 颜色、字阶、20/28px 圆角映射自 Web `styles/tokens.css`。品牌与导航图标由原 SVG 路径转换为 Android VectorDrawable。
- 公开官网和登录页已现场观察；登录后的页面以对应 Web 源码及 API 契约为依据。
- 默认安静、不自动播放、不制造倒计时压力。验证码重发间隔由成功响应后开始计算。

## 已实现

- 登录、Cookie 会话恢复、退出、邮箱注册与验证码请求、密码找回请求。
- 服务端角色工作台；学员与辅导员双角色下按资源归属限制操作。不能自授角色。
- 学员：任务与步骤、开始/暂停/继续、步骤附件与安全检查、完成步骤、提交说明、反馈与训练记录、求助。
- 辅导员：个案资料与记录、方向草稿和确认、SOP 新建/修订/步骤排序/材料/保存/发布、提交审核与指定返工步骤。
- 求助：创建、接收、解决/取消、文字与附件回复。
- 通知、已读、个人资料、阅读与提醒设置。字号在 Android 生效；声音/震动设置同步服务器，首版 Android 始终采用静音文字指引。
- 原生图片和多页 PDF 预览；Storage Access Framework 文件选择，无广泛存储权限。
- 分页、加载/空/错误状态、冲突提示、刷新后保留草稿并显式采用新版本、返回导航和输入保持。

## 安全与状态边界

- 固定 HTTPS origin，拒绝重定向；会话 Cookie 只接受 `__Host-jl_session`、Secure、Path=/、无 Domain，并校验有效期。不会向外部网页传递 Cookie。
- Android Keystore AES-GCM 加密持久会话，不持久化密码。禁用云备份和设备迁移中的应用数据。
- Cookie/CSRF、页面数据和草稿按会话隔离。旧请求在取消或账号切换后不能回填新会话。
- 写接口携带 CSRF；已有资源携带 If-Match，POST 命令携带幂等键。结果未知时重试同一请求和幂等键，停止等待不会伪装成服务端撤销。
- 未收到有效 JSON 成功响应不会显示保存成功；版本冲突不会自动覆盖。
- 图片仅在内存预览，PDF 使用应用私有临时缓存，离开预览或下次启动时清理。
- 请求重试记录当前保留于运行进程内，不是离线写队列。应用进程结束后，应先刷新服务器状态再决定是否重新提交。
- 上传在用户选定文件并点击上传后发生，最大20MB、最多5个，只有服务端标记 ready 的文件可用于提交。扫描/邮件服务不可用会显示实际错误。

## 尚未覆盖及验证限制

- 没有执行生产账号注册、真实邮件发送、真实身份登录或业务数据写入。需要独立的可用测试账号和邮件/扫描服务才能完成生产端到端验收。
- 密码重置链接仍在网页完成；首版不接管邮件深链接。
- 管理员用户管理/认证审核、标注编辑、实时音视频和 AR 不在本首版范围。未提供伪成功入口。
- 辅导员取消训练、训练中覆盖提示等级、反馈标签、个案独立材料目录尚未提供原生编辑入口；训练/求助/SOP 附件及文字审核已实现。
- 原生语音播报和震动尚未启用。声音和震动偏好只同步服务端。
- 签名为本项目隔离的开发测试签名，不是发布签名。不能直接覆盖使用其他签名安装的同包名应用；可能需要先卸载旧测试版本。卸载会移除本机会话。没有创建或上传发布密钥。

## 构建

要求 JDK21、Android SDK35、BuildTools35.0.0、Gradle8.11.1。最低 Android8/API26，目标API35。

```sh
cd android
./gradlew --no-daemon --max-workers=1 :core:test :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

发布版源码可用 `:app:assembleRelease` 编译未签名包；不包含发布签名配置或凭据。

云端工具链适配脚本 `tools/build_cloud.py` 仅用于本次执行环境，普通开发机使用上面的 Gradle wrapper 命令即可。Wrapper 分发包 SHA256 已锁定。
