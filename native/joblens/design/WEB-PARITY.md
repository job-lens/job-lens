## 角色和动画来源

`web-reference/Buddy.tsx`、`Buddy.css`、`Companions.tsx`、`Companions.module.css` 与 `WorkIllustration.tsx` 是本次基准的未改动原文件。小融保留深棕齐刘海、米白降噪耳机、细长眼睛与蓝色毛衣。原源码虽有“小芽”的旧注释，当前 SVG 和当前线上像素没有小芽，Android 没有凭注释另造造型。

原生重现 4.2s 呼吸、5s 刘海轻摆、5.6s 眨眼和双周期缓慢张望。暂停设置持续保存，系统动画比例为0时停动，页面不在前台时停动。点击有1.6s笑眼；密码获得焦点时闭眼。手机端采用原生点击与自然张望，桌面 Web 的全屏鼠标跟随不直接搬到触屏。

认证标题使用系统已安装的官方 Noto Serif CJK SC 字体之8字子集（7.1KB），避免 Android 的中文 serif 回退成无衬线。许可证附于 `Noto-Serif-CJK-LICENSE.txt` 和 APK assets。工作区则依照 `App.module.css` 的实际覆盖规则使用无衬线 26sp/半粗主标题，而不是误套全局衬线令牌。

## 适配与验证边界

Android 保留系统状态栏、返回键、键盘、字体缩放、无障碍语义和48dp触控目标。Web 的浏览器地址栏不作为应用内容。原生材料/附件选择、预览和对话框采用 Android 控件。窄屏截图重点对应 Web 手机布局；不声称像素级复制桌面三栏。

本次截图中，生产登录页来自真实 APK。需要账号的场景以独立 androidTest 的合成数据触发并在画面标注。API、会话、所有权、幂等和未知结果核心没有因视觉修正而更改。注册邮件仍由服务端决定，客户端保留“邮件服务暂不可用”的失败提示。
