# 邮箱账号

关联 Issue #42；接在已有 Cookie/CSRF 身份模块上，不引入第二套认证。注册政策来自 Issue #22：开放注册，初始仅有 `learner` 角色。请求体禁止额外字段，不能提交角色或个案授权。

## 行为

- `POST /auth/registration-code`：Origin/预登录 CSRF，邮箱规范化；6 位密码学随机验证码，Argon2 摘要，5 分钟有效，60 秒重发间隔，最多 5 次校验。邮件适配器未配置或拒绝投递返回 503，不展示假成功。
- `POST /auth/register`：验证邮箱后，在同一事务创建用户、学员角色、资料、安静偏好并消费验证码，轮换 Cookie/CSRF。账号重复返回 409，重放验证码返回 400。
- `POST /auth/password-reset-requests`：限流在用户查找之前执行；已注册与未知邮箱得到相同 202 及邮件内容。只有关联活跃账号的令牌可以重置密码。
- `POST /auth/password-resets`：43 字符随机令牌，数据库只存 SHA-256 摘要，15 分钟有效，单次使用。原子更新密码与凭据版本，所有设备的旧会话立即无法通过认证。登录与重置锁定同一用户，避免旧密码登录与重置竞争时产生可用旧会话。
- 找回令牌使用 URL fragment，不发送给页面服务器；页面读取后立即移除地址栏 fragment，不写入持久存储。重置后清除私人前端缓存并要求重新登录。

页面 `/register`、`/forgot-password`、`/reset-password` 与沉浸登录共享设计规范。验证码明确提示发送成功或投递失败，不模拟真实注册、上传或提交。

## 独立发信配置与验收

适配器按 [Resend 官方接口](https://resend.com/docs/api-reference/emails/send-email) 调用固定 HTTPS 地址。需在 Job Lens 自己的忽略配置或进程环境中设置 `JOB_LENS_MAIL_API_KEY` 与 `JOB_LENS_MAIL_FROM`。发件人需要在该项目自己的供应商配置中验证。不要复制群学、Windup 或其他项目的密钥、用户库、环境文件；不要把密钥提交到 Git 或发在聊天中。

本地相关验收包含真实 PostgreSQL 注册/找回事务、旧会话回归、单次/过期/错误码/权限注入、投递失败回滚和真实供应商请求结构的隔离测试。隔离测试收件箱仅作为测试替身，不是开发态发信实现。

尚未完成的外部验收：独立供应商配置后，真实收件箱收到验证码与找回链接，并在浏览器完成注册、退出、找回、重新登录。未拿到配置前保持 Issue #42 开放，不宣称邮件送达。辅导员认证审核人及个案分配规则仍由 Issue #22 决定，不创建生产权限。
