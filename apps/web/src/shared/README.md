# shared

两端共用的东西放这里。`app` 组合页面，`features` 写业务，`shared` 只收真正共用的能力。

## 准入规则

出现**第二个**使用方时上移到 `shared`，不是预感会共用就先放进来。反过来，一旦某个 `features/*` 里的组件被第二个 feature 需要，立刻上移，不要复制——两份实现会各自长出不同的焦点行为和读屏名称，而这些是验收项。

`shared/ui` 收无业务含义的呈现组件；带业务语义的留在 feature 里。

## 已有能力

| 目录 | 用途 |
| --- | --- |
| `api` | 契约生成的类型化请求客户端、`ApiError`、命令请求头 |
| `platform` | 设备能力（选图、语音、震动）与失败分类 |
| `preferences` | 本人界面偏好；字号写入 CSS 变量，语音与震动经 `usePrompt` 自动带上 |
| `ui` | 加载、错误、空态等呈现组件 |

## 无障碍

字号、音量、安静模式是这个产品的核心功能，不是附属设置。任何会发声或震动的调用都走 `usePrompt`，不要直接用 `usePlatform` 自己拼偏好对象——那是唯一会漏掉安静模式的写法。
